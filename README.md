## 💻 Getting Started Locally

### Prerequisites

- **Flutter SDK**: `^3.24.0` or `>=3.32.0`
- **Dart SDK**: `^3.5.0`
- **JDK**: Java 17 (`temurin-17` or `zulu-17`)
- **Xcode**: 15+ (for iOS/macOS compilation)
- **CocoaPods**: `1.16.0+`
- **Android Studio** with Android SDK Platform 35 / 36

### Installation & Execution

1. **Clone the repository**:
   ```bash
   git clone https://github.com/JayDutta7/Portfolio.git
   cd Portfolio
   ```

2. **Configure environment keys**:
   Copy the example environment template and supply your Firebase credentials:
   ```bash
   cp .env.example .env
   ```

3. **Install dependencies**:
   ```bash
   flutter pub get
   ```

4. **Run locally on your desired platform**:
   ```bash
   # Web (Debug / Chrome)
   flutter run -d chrome

   # Web (Production Release Mode on Port 8080)
   flutter run -d chrome --release --dart-define-from-file=.env --web-port=8080

   # macOS Desktop
   flutter run -d macos

   # Android (Connected device or emulator)
   flutter run -d android

   # iOS (Connected iPhone or simulator)
   flutter run -d ios
   ```
